# 프로젝트 주제

**허니팟 기반 재공격 탐지 기능을 갖춘 웹 취약점 진단 및 대응 시스템 개발**(성적 변조 시나리오)

본 프로젝트에서는 가상의 학교 성적관리 웹서비스를 직접 구축하고, 대표적인 웹 취약점을 재현하여 보안 문제를 분석한다. 

이후 취약한 코드를 수정하고, WAF와 허니팟을 활용하여 공격 요청을 탐지·차단하는 보안 시스템을 구현한다.

### AI 역할 및 활용 계획

AI는 취약점 원리 학습, 코드 오류 분석, 테스트 항목 검토 및 보고서 문장 정리의 보조 도구로 활용할 계획이다. 시나리오 설계와 핵심 기능 구현, 공격·방어 실험 및 결과 분석은 팀원이 직접 수행하며, AI가 제안한 내용은 팀 내 검토와 실제 테스트를 거쳐 적용할 예정이다.

# 개발 배경 및 목적

# 1. 개발 배경

최근 웹 애플리케이션은 학교, 기업, 공공기관 등 다양한 분야에서 사용자 정보와 중요 데이터를 관리하는 핵심 서비스로 활용되고 있다. 이에 따라 웹 서비스를 대상으로 한 사이버 공격도 지속적으로 발생하고 있으며, SQL Injection, XSS(Cross-Site Scripting), Path Traversal과 같은 웹 취약점은 개인정보 유출, 데이터 변조 및 비인가 접근 등의 보안 사고로 이어질 수 있다.

특히 웹 애플리케이션의 취약점을 사전에 발견하고 제거하는 것뿐만 아니라, 취약점 개선 이후에도 지속적으로 발생할 수 있는 공격 시도를 탐지하고 대응하는 보안 체계의 중요성이 커지고 있다. 기존의 단순한 취약점 점검과 패치만으로는 반복적인 공격 시도나 공격 패턴의 변화를 파악하는 데 한계가 있으므로, 취약점 진단과 함께 공격 탐지, 기록 및 분석 기능을 연계할 필요가 있다.

이에 본 프로젝트에서는 학교 성적 관리 시스템을 모티브로 한 모의 웹 서비스를 구축하고, SQL Injection, XSS, Path Traversal 등 주요 웹 취약점을 직접 구현하여 공격을 재현하고자 한다. 또한 취약점별 시큐어 코딩 기법을 적용하여 보안 문제를 개선하고, 규칙 기반 미니 WAF와 허니팟을 연계하여 공격 시도를 탐지하고 기록하는 환경을 구축하고자 한다.

# 2. 개발 목적

본 프로젝트의 목적은 직접 구현한 모의 웹 서비스를 대상으로 주요 웹 취약점을 진단하고, 공격 재현부터 취약점 개선, 공격 탐지 및 재공격 대응까지 이어지는 통합적인 웹 보안 환경을 구축하는 것이다.

첫째, SQL Injection, XSS, Path Traversal 등 주요 웹 취약점의 발생 원리와 공격 방식을 이해하고, 실제 웹 서비스에 적용하여 취약점 진단 및 공격 재현 역량을 기르고자 한다.

둘째, 매개변수화 쿼리, 출력 인코딩, 경로 정규화 및 접근 권한 검증 등의 시큐어 코딩 기법을 적용하여 취약점을 개선하고, 동일한 공격을 재수행하여 보안 조치의 효과를 검증하고자 한다.

셋째, 규칙 기반 미니 WAF를 구현하여 악성 요청을 탐지하고 차단하며, 보안 감사 로거를 통해 공격 시각, 요청 경로, 공격 유형 및 대응 결과 등을 기록하고 분석하는 방법을 학습하고자 한다.

넷째, 별도의 허니팟 환경을 구축하여 취약점 개선 이후에도 지속되는 공격 시도를 유도하고, 반복적인 접근 및 공격 패턴을 탐지함으로써 재공격에 대응할 수 있는 보안 체계를 구현하고자 한다. 또한 서버 측 세션 폐기, 성적 데이터 복구 및 IP 차단 등의 대응 기능을 연계하고자 한다.

마지막으로 취약점 개선 전후의 공격 성공 여부, 공격 탐지 및 차단율, 정상 요청에 대한 오탐 여부 등을 비교·분석하고, 이를 바탕으로 보안 진단 보고서를 작성하고자 한다. 이를 통해 웹 모의해킹, 취약점 진단, 시큐어 코딩 및 보안 모니터링에 필요한 실무 역량을 습득하는 것을 목표로 한다.

# 주요 기능 및 요구사항

### 1. 시나리오 설명

가상의 학교 성적 관리 웹서비스를 구축하고, 로그인·게시판·파일 조회 기능에서 SQL Injection, XSS, Path Traversal 취약점을 각각 재현한다. SQL Injection을 통한 교수 계정 인증 우회 및 가상 학생 성적 변조를 중심 시나리오로 구성하며, 게시판 스크립트 실행과 허용 범위 밖의 실습용 파일 접근도 함께 진단한다.

이후 취약한 코드를 수정하고, 침해 세션 폐기와 성적 복구를 수행한다. 규칙 기반 미니 WAF로 악성 요청을 탐지·차단하며, 사전에 정의한 재공격 조건에 해당하는 요청은 별도 허니팟으로 전달하여 후속 행위를 기록한다. 수집한 로그를 바탕으로 최초 공격과 재공격의 연관성을 분석하고, 보안 조치 전후의 공격 성공 여부와 정상 요청에 대한 오탐 여부를 비교한다.

# 기대 효과 및 학습 목표

### 학습 목표

본 프로젝트는 직접 구현한 모의 웹 서비스를 대상으로 주요 웹 취약점을 진단하고, 실제 공격을 재현한 뒤 취약점 개선 및 재검증까지 수행하는 전반적인 웹 보안 업무 과정을 학습하는 데 목적이 있다.

먼저 SQL Injection, XSS, Path Traversal 등 대표적인 웹 취약점의 발생 원리와 공격 방식을 이해하고, OWASP Top 10 및 KISA 웹 취약점 점검 가이드를 기준으로 웹 애플리케이션의 보안 취약점을 분석하는 역량을 기르고자 한다. 이를 통해 단순히 취약점의 개념을 이해하는 수준을 넘어, 실제 코드와 HTTP 요청·응답을 분석하여 취약점이 발생하는 원인과 공격에 따른 영향을 직접 확인하는 것을 목표로 한다.

또한 발견한 취약점에 대해 매개변수화 쿼리, 출력 인코딩, 입력값 및 경로 검증 등의 시큐어 코딩 기법을 적용하고, 규칙 기반 미니 WAF를 구현하여 악성 요청을 탐지하고 차단하는 방법을 학습하고자 한다. 이 과정에서 취약점별 적절한 방어 기법을 이해하고, 정상적인 서비스 이용에 영향을 주지 않으면서 공격을 효과적으로 차단할 수 있는 보안 설계 역량을 기르고자 한다.

나아가 보안 감사 로거와 허니팟을 연계하여 공격 및 차단 기록을 수집하고, 이를 바탕으로 공격 발생 시점과 행위, 피해 범위를 분석하는 경험을 쌓고자 한다. 특히 최초 진단에서 발견한 취약점이 개선된 이후에도 유사한 공격이 재시도되는 상황을 고려하여, 재공격 탐지와 로그 기반의 사고 분석 능력을 함께 학습하는 것을 목표로 한다.

마지막으로 취약점 진단 결과를 체계적인 보고서로 작성하고, 보안 조치 이후 동일한 진단을 반복하여 개선 여부를 검증하는 과정을 수행하고자 한다. 이를 통해 실제 보안 업계에서 활용되는 모의해킹, 취약점 진단, 보고서 작성 및 보안 조치 검증에 필요한 실무 역량을 습득하고자 한다.

### 기대 효과

본 프로젝트를 통해 웹 애플리케이션의 취약점 발견부터 공격 재현, 원인 분석, 보안 조치 및 재진단에 이르는 일련의 과정을 직접 경험할 수 있을 것으로 기대한다. 특히 직접 개발한 웹 서비스를 대상으로 공격을 수행하고 방어 기법을 적용함으로써, 개발자 관점의 시큐어 코딩과 공격자 관점의 취약점 분석 능력을 함께 향상시킬 수 있다는 점에서 의의가 있다.

또한 OWASP Top 10과 KISA 웹 취약점 점검 가이드를 기반으로 진단 항목을 구성하고, 발견한 취약점과 공격 결과, 위험도 및 개선 방안을 포함한 보안 진단 보고서를 작성함으로써 실제 보안 컨설팅 및 모의해킹 업무에서 요구되는 취약점 분석과 기술 문서 작성 능력을 향상시킬 수 있다.

아울러 미니 WAF와 보안 감사 로거를 구현하여 악성 요청을 탐지하고 차단하는 과정뿐만 아니라, 공격 시도와 대응 결과를 객관적인 기록으로 남기는 체계를 구축할 수 있다. 이를 통해 단순한 공격 차단을 넘어 로그를 활용한 공격 패턴 분석과 재공격 탐지 등 능동적인 보안 대응의 중요성을 이해할 수 있을 것으로 기대한다.

마지막으로 취약점 조치 전후의 결과를 비교하고 정상 요청에 대한 오탐 여부까지 검증함으로써 보안 조치의 실효성을 객관적으로 평가할 수 있다. 프로젝트 결과물인 모의 웹 서비스, 취약점 진단 보고서, 방어 모듈 및 검증 결과는 향후 웹 보안 학습과 실무 프로젝트에 활용할 수 있으며, 웹 모의해킹 및 취약점 진단 분야로 진출하기 위한 실무 중심의 포트폴리오로도 활용할 수 있을 것으로 기대한다.
